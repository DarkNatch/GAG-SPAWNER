🌱 Grow a Garden Script

Grow a Garden is a Roblox farming helper script that allows players to:

Spawn custom pets with weighted names

Plant different seed types

View data tables and about info

Use an easy-to-navigate OrionLib UI



---

📦 Features

🐾 Pet Spawner: Input pet weight and spawn pets dynamically

🌱 Seed Spawner: Input seed type and spawn seeds

📊 Data Table: Shows game logic summary with clean design

📢 About Us: Add your name and social links here!



---

🛠️ How to Use

1. Add all files from this repository to your Roblox Studio game.


2. Place loader.lua inside StarterPlayer > StarterPlayerScripts.


3. Make sure modules folder and OrionLib.lua are included.


4. Start the game. The UI will load automatically.




---

🗂️ File Structure

GrowAGarden/
├── loader.lua                -- Main loader
├── OrionLib.lua              -- Orion UI library
└── modules/
    ├── pets.lua              -- Pet features
    ├── seeds.lua             -- Seed features
    ├── data_table.lua        -- Data table tab
    └── about_us.lua          -- About tab


---

🎨 UI Tabs

Tab	Purpose

Pet Features	Input pet weight and spawn a pet cube
Seed Features	Input seed name and spawn a seed
Data Table	See seed/pet summary
